# 拦截管理 PRD

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品模块 | 库内管理 / 拦截管理 |
| 文档版本 | v1.0 |
| 编写日期 | 2026-09-03 |
| 原型页面 | `staging-inventory.html` |
| 目标用户 | 客服、仓库操作员、仓库主管、财务/核销人员 |

## 2. 背景

海外仓在出库、暂存、拆柜、入库等环节中，经常收到客户临时暂停出库、变更派送计划、转入暂存、重新贴标、撤回出库指令等诉求。拦截管理用于集中承接这些拦截申请，并支撑审批、仓库执行、失败原因记录、费用维护、附件管理、日志追溯和导出。

当前拦截管理板块已在本地页面中实现基础原型，入口位于侧边栏“库内管理 / 拦截管理”。

## 3. 目标

1. 建立拦截申请从待审批到拦截执行、完成或拒绝的统一处理链路。
2. 支持客服和仓库在同一列表中按状态、客户、入仓号、柜号等维度快速定位任务。
3. 对拦截失败任务记录并展示“失败原因”，便于客服同步客户和后续重提拦截。
4. 对拦截成功任务自动生成暂存单，并联动暂存库存。
5. 保留完整操作日志，列表不展示处理人和处理时间，相关信息通过日志查询。
6. 支持指令费用、附件、备注、日志和导出，满足操作和追溯需要。

## 4. 用户角色

| 角色 | 主要诉求 |
| --- | --- |
| 客服 | 提交/跟进客户拦截诉求，查看状态、失败原因、日志和附件 |
| 仓库操作员 | 审批通过后执行拦截，标记拦截成功或失败，维护费用和附件 |
| 仓库主管 | 查看任务处理结果，按需导出、归档和追溯日志 |
| 财务/核销人员 | 查看指令费用和核销状态，确认费用处理进度 |

### 5.1 本期范围

- 拦截任务列表
- 多条件筛选
- 状态标签页

## 6. 核心状态

| 原始/业务状态 | 列表展示状态 | 说明 |
| --- | --- | --- |
| 待处理 | 待审批 | 拦截申请已提交，等待处理 |
| 已确认 / 拦截中 | 拦截中 | 已通过审批，仓库正在执行 |
| 已完成 / 拦截成功 | 拦截成功 | 拦截成功，货物转入暂存并生成暂存单 |
| 拦截失败 | 拦截失败 | 拦截执行失败，需要记录失败原因 |
| 审批拒绝 / 已取消 / 已驳回 | 审批拒绝 | 拦截申请未进入执行或被拒绝 |

状态页签：

- 待审批
- 拦截中
- 已完成
- 审批拒绝
- 全部

说明：

- “已完成”页签聚合展示拦截成功和拦截失败任务。
- “已完成”页签中，拦截失败任务需展示“失败原因”列。
- 拦截成功任务没有失败原因，失败原因列显示 `-`。

## 8. 批量操作

| 页签 | 可用操作 | 说明 |
| --- | --- | --- |
| 待审批 | 审批通过、审批拒绝、批量内部备注、导出 | 审批拒绝需填写处理原因 |
| 拦截中 | 拦截成功、拦截失败、批量内部备注、导出 | 拦截失败需填写失败原因 |
| 已完成 | 导出 | 不展示内部备注批量按钮 |
| 审批拒绝 | 导出 | 不展示内部备注批量按钮 |
| 全部 | 导出 | 不展示内部备注批量按钮 |

### 8.1 审批通过

规则：

1. 仅待审批任务可审批通过。
2. 若任务存在待核销或部分核销费用，需二次确认。
3. 若货物已出库，审批通过时自动归入审批拒绝，并记录日志。
4. 正常审批通过后，任务进入拦截中。

日志：

- 操作内容：审批通过
- 操作前：待审批
- 操作后：拦截中
- 操作人：当前处理人
- 操作时间：当前时间

### 8.2 审批拒绝

规则：

1. 仅待审批任务可审批拒绝。
2. 单条或批量审批拒绝均需填写处理原因。
3. 提交后任务进入审批拒绝。
4. 拒绝原因记录到 `terminationReason`，并在审批拒绝页签动态列展示。

### 8.3 拦截成功

规则：

1. 仅拦截中任务可标记拦截成功。
2. 拦截成功不要求填写失败原因。
3. 拦截成功后状态进入已完成，列表“拦截结果”显示拦截成功。
4. 自动生成暂存单号，货物状态更新为暂存中。
5. 自动写入暂存库存。
6. 记录操作日志。

字段写入：

| 字段 | 规则 |
| --- | --- |
| `status` | 已完成 |
| `cargoStatus` | 暂存中 |
| `inventoryStatus` | 暂存 |
| `outboundStatus` | 未出库 |
| `actualBoxes` | 实际拦截箱数，默认取申请箱数 |
| `storageNo` | 自动生成暂存单号 |
| `resultRemark` | 拦截成功说明 |

### 8.4 拦截失败

规则：

1. 仅拦截中任务可标记拦截失败。
2. 点击拦截失败后弹出失败原因填写弹窗。
3. 失败原因弹窗居中展示，失败原因必填，最大 200 字。
4. 提交后任务进入已完成聚合页签，列表“拦截结果”显示拦截失败。
5. 已完成列表动态展示“失败原因”列。
6. 失败原因记录到 `failReason` 和 `terminationReason`。
7. 记录操作日志。

字段写入：

| 字段 | 规则 |
| --- | --- |
| `status` | 拦截失败 |
| `terminationType` | 拦截失败 |
| `failReason` | 用户填写的失败原因 |
| `terminationReason` | 同失败原因 |
| `resultRemark` | 清空 |

## 10. 指令费用

费用列表字段：

- 计费时间
- 费用名称
- 费用类型
- 计费单位
- 汇率
- 计费单价
- 计费数量
- 币种
- 原币应收金额
- 人民币应收金额
- 添加时间
- 添加人
- 费用备注
- 指令备注
- 图片
- 指令状态
- 操作

规则：

1. 支持新增、编辑、删除费用。
2. 费用名称、计费时间、单价、数量、汇率为保存校验项。
3. 汇率默认 1。
4. 原币应收金额 = 单价 × 数量。
5. 人民币应收金额 = 原币应收金额 × 汇率。
6. 图片最多 9 张。
7. 指令状态支持待处理和已处理。
8. 待审批和拦截中任务允许编辑指令状态。
9. 核销状态由任务字段或费用数量推导展示。

## 14. 导出

入口：

- 列表右侧“导出”按钮。

规则：

1. 仅导出当前可见并已勾选的任务。
2. 未勾选任务时给出提示。
3. 文件名格式：`拦截管理_{当前页签}_{日期}.csv`。
4. 导出字段与当前列表字段保持一致。
5. 全部导出需包含“拦截结果”；已完成导出需包含“拦截结果”和“失败原因”。
6. 审批拒绝导出需包含“审批拒绝原因”。
7. 导出不包含处理人和处理时间。

## 15. 拆柜后重新发起拦截

适用场景：

- 原任务为拆柜前拦截。
- 原任务状态为审批拒绝或拦截失败。
- 原任务存在失败原因。

规则：

1. 用户点击“发起拆柜后拦截”。
2. 系统检查是否已有基于该单的待处理或拦截中重试任务。
3. 若存在，提示已有任务并禁止重复创建。
4. 若不存在，二次确认后创建新任务。
5. 新任务进入待审批。
6. 新任务拦截类型为拆柜后拦截。
7. 新任务清空失败原因、取消原因、结果说明和费用。
8. 原任务和新任务均记录日志。

## 18. 校验和异常

| 场景 | 规则 |
| --- | --- |
| 未勾选任务执行批量操作 | Toast 提示“请勾选运单” |
| 审批拒绝未填原因 | 阻止提交并提示 |
| 拦截失败未填原因 | 阻止提交并提示 |
| 费用信息不完整 | 阻止保存并提示完善费用名称、计费时间、单价、数量和汇率 |
| 文件未选择 | 阻止附件保存并提示 |

| 已出库任务审批通过 | 自动进入审批拒绝并记录原因 |

## 19. 验收标准

1. 点击“拦截管理”后进入拦截管理页面，标题和侧边栏状态正确。
2. 各筛选条件可独立或组合生效。
3. 状态页签数量随 mock 数据动态变化。
4. 待审批页签支持审批通过、审批拒绝和批量内部备注。
5. 拦截中页签支持拦截成功和拦截失败。
6. 点击拦截失败后必须弹出失败原因弹窗，未填写不能提交。
7. 拦截失败提交后进入已完成页签，列表展示拦截结果为拦截失败，并展示失败原因。
8. 拦截成功后进入已完成页签，列表展示拦截结果为拦截成功，失败原因显示 `-`。
9. 已完成列表不展示处理人和处理时间。
10. 列表日志入口可查看操作人和操作时间。
11. 详情抽屉可查看基础信息、货箱信息、指令费用和附件。
12. 指令费用支持新增、编辑、删除、金额计算和状态维护。
13. 附件支持上传、编辑、下载和删除。
14. 客户备注和内部备注修改后列表和详情同步刷新。
15. 导出文件包含当前列表字段，不包含处理人和处理时间。
16. 全部导出包含拦截结果字段，已完成导出包含拦截结果和失败原因字段。
17. 拆柜前拦截失败且存在失败原因时，可重新发起拆柜后拦截。

## 20. 后续建议

1. 明确拦截成功是否完全无弹窗，若无弹窗，需要前端直接执行成功流转并自动生成暂存单。
2. 明确不同角色对审批、费用、附件、导出的权限。
3. 明确后端状态枚举是否保留“已完成”作为成功状态，或改为“拦截成功/拦截失败”两个终态。
4. 明确失败原因和审批拒绝原因是否需要独立字段，避免 `terminationReason` 混用。
5. 接入真实接口后补充接口 PRD、字段字典和错误码。
